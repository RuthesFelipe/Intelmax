# IntelMax — Soluções Tecnológicas

Landing page institucional da IntelMax, apresentando o **Armário Inteligente**: cofre modular contra furtos e assaltos de estoques de alto valor (smartphones e eletrônicos), com abertura por biometria/cartão, monitoramento web em tempo real, CFTV interna e integração com central de alarme.

## Estrutura

- `index.html` — página única (HTML + CSS + SVG inline, sem dependências externas).
- `assets/` — logotipos oficiais em PNG com fundo transparente (extraídos do manual da marca) e favicon.

## Como visualizar

Abra o `index.html` diretamente no navegador, ou sirva localmente:

```bash
npx serve .
```

## Publicação

Por ser um site estático de arquivo único, pode ser hospedado em qualquer serviço: GitHub Pages, Vercel, Netlify ou servidor próprio.
